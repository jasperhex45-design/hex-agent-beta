# HEX 名称与目录

| 层级 | 当前名称或入口 |
| --- | --- |
| 产品名 | Hex Agent / HEX |
| 运行命令 | `hex-agent`、`python -m hex_agent` |
| 实际实现 | `liu_agent/` |
| 入口与兼容模块 | `hex_agent/`、`cl_hex/` |
| 安装元数据名 | `cl-hex` |
| 开发仓库布局 | `hex-agent/` 下为当前工程 |
| 独立内测包布局 | 解压根目录就是当前工程 |

内部名称用于兼容现有脚本和任务记录，不表示多个独立产品。版本读取 `pyproject.toml`；源码包另在 `MANIFEST.json` 中记录发行渠道和文件摘要。

原开发历史保留在私有开发库，独立内测包不带旧源码目录、图片、任务和 Git 历史。已有任务的原始记录不因名称整理而重写。安装副本以实际路径绑定为准，不从旧目录名猜测当前运行位置。
