# HEX 共用创作方法

此文是根 Skill 的可读方法说明，供 Harness 宿主和没有执行能力的新会话共用。具体命令与状态合同只适用于真实运行的 Harness；本说明不创建任务状态，也不解除已有任务的锁、拒绝或预算。

## 从需求到交付

1. **理解。** 读取原话、素材与本题已有回答，确认用途、观众首先要感受到什么、必须保留什么、允许改变什么、以及图片/编辑/提示词/资料交付。分清用户要求、宿主提案和未知项。
2. **问询。** 会改变结果的歧义先问；目标生图模型或服务未确定且没有选型委托时必须问。第一轮直接用当前宿主真实且适用于本题的选择组件，2–4 个贴题选项加自由填写，遵守宿主更小的上限，最多两个关键问题。明确的“HEX 研究后决定”只委托对应表达决定；不扩大成选型授权。已有答案直接沿用。
3. **研究。** 按 [研究入口](../knowledge/research-entrypoints.md) 的缺口选择来源。Designeer 用于不同素材/信息入口，接着读原始作品、字体、配色、材质或方法来源；Pinterest 是视觉来源之一。实际看图才写作品观察，文字摘要不冒充视觉研究。没工具/没来源就指出未验证部分。
4. **判断。** 将参考中可见的主次、相对尺度、空间、光色、材质或观看关系转成本题方案，说明采用什么、为什么适合、舍弃什么；不堆叠风格词，不用模型写法代替设计。研究按决定是否有依据收束，不固定方向数或自动为每个方向生图。
5. **适配提示词。** 先读 [模型索引](../knowledge/model-prompts/README.md) 和已选卡，以模型实际版本/模式表达已确定方案。精确文案、数量、身份、参考职责、修改范围不能漂移。正文与接口设置分开，缓存不存在的版本或接口冲突才补查官方来源。后端未知的已选内置服务使用通用指导，不借其它模型卡。
6. **执行和判断结果。** Harness 模式继续当前 host_context/冻结/派发与回执；指导方式只调用当前确有、已选择且参数可核对的宿主原生工具，明确未经过 Harness 验证。建任务时确定探索首稿或正式/高风险交付，未知默认正式；探索首稿可实际看图自检并标明未独立评审，正式/高风险交付须隔离评审。不得因失败或工具缺失中途降级。提示词任务交付可复制正文；图像任务展示真实图片，实际看图后说明得到什么、缺什么。硬要求与整体目标成立、仅作者局部拍法有偏差时，披露具体差异后由用户确认收下；原检查保持，不宣称全部通过。没有图就不声称已验证成图；文件检查、视觉判断和用户接受分开。

## 按题材加载方法

- 单车静态外观：读取 [汽车方法](../.agents/skills/cl-hex-car-photography/SKILL.md) 的摄影、身份与参考职责部分。
- 人物、平面海报、分镜静帧、一般改图：读取 [通用视觉方法](../.agents/skills/liu-aesthetic-agent/SKILL.md)；开放研究需要 [设计研究](../.agents/skills/liu-aesthetic-agent/references/design-study.md)。
- 风格取舍和修订收益：按需读 [审美判断](../.agents/skills/liu-aesthetic-judgment/SKILL.md)。
- 绘画空间组织：按需读 [绘画结构](../.agents/skills/liu-art-structure/SKILL.md)。

指导方式读取这些文档的设计方法；其中 car prepare、host_context、schema、run、冻结、派发与回执命令仅在 Harness 模式执行，绝不是指导方式的前置要求。指导方式不因缺少这些命令停下可完成的创作分析，也不能伪造执行结果或用文字摘要冒充状态证据。取得执行能力后，先核对是否已有任务，再按原合同或新的真实流程继续。

## 修改与测试

开放题的必要研究因来源不可访问或持续无决策增量而无法继续时，保存真实尝试与未解决问题，披露研究不足，沿原授权和预算自主首稿；不伪造研究完成。明确必做研究和关键身份/文字/父图/范围未决时保留阻塞。

根据用户对真实图片的反馈保留正确部分，明确父图与修改范围，在原授权内有限修改；仅已有明确返修授权、剩余预算和可控修法的具体错误可自主修一次，保留首稿，仍失败就停；审美分歧先展示。预算、拒绝或失败不能靠切换方式绕过。用户只要参考或方案时在该阶段交付，不自动生图。没有新证据或控制的同类失败不反复乱试。

用户要求验证 HEX 是否优化时，按已授权范围明确基线、相同需求与实际工具条件，展示真实并列结果与可见差距。单图、程序通过或主观自评不证明优化有效；不把一次相对胜出推广为所有模型/宿主稳定优势，也不在日常任务自动多生图。
