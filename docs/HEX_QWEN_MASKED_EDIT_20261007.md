# Qwen 原画布局部蒙版编辑

`comfyui.qwen-image-masked-edit` 是可选的实验编辑路线，使用本地 ComfyUI 和 `qwen-image` 目标模型。它在二值蒙版范围内采样，并把保护区域合成回父图。需要先具备 [Qwen 单父图编辑](HEX_QWEN_SINGLE_PARENT_EDIT_20261007.md) 所述环境，再明确选择此入口；普通编辑不会自动启用它。

## 必需输入

- 一张已观察、已登记的任务内 PNG 父图。
- 与父图尺寸一致的二值 PNG `edit_mask`：白色可编辑，黑色保护，两种区域都必须存在。
- 蒙版为不透明灰度或 RGB；RGB 三个通道数值一致，像素仅为 0 或 255。
- 原画布宽高均为 32 的倍数，`reference_resolution=0`，冻结输出尺寸等于父图尺寸；不隐式裁剪或缩放。

`provider_options.edit_mask` 只包含任务内 `file` 和真实 `sha256`。父图、蒙版、正文与实际图结构共同冻结，上传后逐一回读核对。

当前图结构保留 `TextEncodeQwenImage21` 的父图与 VAE 参考，将父图的 `VAEEncode` latent 经 `SetLatentNoiseMask` 送入采样；解码后由 `ImageCompositeMasked` 恢复保护区域。

## 可选软边合成

需要软边时，额外同时提供 `composite_alpha` 与 `protection_mask`；两者各自绑定任务内 `file` 和真实 `sha256`，与父图同尺寸。

| 输入 | 作用 |
|---|---|
| `edit_mask` | 二值采样范围，白色允许采样修改 |
| `composite_alpha` | 单次最终合成权重；包含 0、255 和中间灰度，分别代表保留、完整采用和过渡 |
| `protection_mask` | 独立二值硬保护；白色强制保留父图，优先于软 alpha |

最终有效 alpha 为 `alpha × (1 − protection)`，不得为空或超出采样范围。只对同次采样尚未合成的解码 RGB 应用一次。软边不是姿态条件，具体保护区和边缘宽度由实际图像决定。

软边模式额外保存同次采样的 `decoded-original.png` 及摘要。查询必须取得并核对原解码与合成结果，才能登记合成候选；这不是第二次生成。普通二值模式沿原冻结图结构运行。

## 检查与恢复

执行器保存 `protected-pixels-check.json`，核对最终保护区域的 RGB 像素与父图完全一致。二值模式检查蒙版外区域；软边模式检查有效 alpha 为零的区域及硬保护白区。

保护检查失败时记录失败并保留证据，不自动重发。缺失原解码或请求状态未知时，只查询原请求编号。重复执行或查询同一请求不新增提交。流程继续使用原 dispatch、授权、停止记录和累计预算；更改蒙版或方案须重新建立与冻结对应版本。

像素保护检查不涵盖元数据或透明通道，也不证明生成区域的身份、动作、接触、接缝或视觉质量合格。当前入口没有姿态或关节控制；引导图若没有真实节点绑定，不能称为已生效的姿态条件。宿主仍需对照父图与输出完成本题视觉检查。
