# Qwen Image：按任务选择写法

checked: 2026-10-12；状态：官方资料已核对，HEX 图像效果仍为 experimental。
本卡是提示词知识缓存，不表示新模型、官方 PE 或多图 API 已接入。

## 1. 先确认型号、入口与任务

- 本工程现有档案对应本地 Qwen-Image-2.1 INT8 路线；既有连接器限制见 `knowledge/models/qwen-image.json`。
- 官方另有 Qwen-Image-2.1-Turbo 与托管 Pro/Turbo API，不能用同一档采样参数推断它们的实际行为。[Q1]
- Qwen3-VL、Qwen PE 是理解或提示词重写层，不是最终生图模型。
- 用户未说目标模型且当前任务没有已确认选择时，先问“这次准备在哪个模型和入口使用？”
- 再区分：从零生成、把当前图局部修改、借参考主体另创画面；有参考图不自动等于编辑当前画布。
- 核心目标模糊先向用户提问，得到回答后才扩写；官方 PE 的补全规则不能覆盖此要求。

## 2. 官方资料明确了什么

- T2I 重写器用英文观察式描述组织成品画面，保留用户指定的对象、数量、颜色、位置及逐字文案。[Q2]
- 它按背景、分区或单主体组织内容，交代空间、材质、光源和文字位置；比例由独立字段承载。[Q2]
- 约 400–500 词、8–14 个位置短语是该官方 PE 范式，不是每条 Qwen prompt 的最低门槛。[Q2]
- Edit 重写器以编辑操作开头，明确哪些属性改变，保持其余内容；保留项避免整幅重新描写。[Q3]
- Edit 的说明语言与画内文字语言分别处理；中文指令可用中文说明，准确文案仍按用户指定字符与语言。[Q3]
- 多图标签、画布选择和比例字段是官方 PE 协议的一部分，只有实际采用该协议才照此组织。[Q3]

## 3. HEX 整理：从零生成

以下是可复用组织骨架，不是逐字复制的官方固定模板：

```text
[媒介与风格]的[主体、动作或状态]，位于[场景与背景]。
[主体和关键元素的空间关系]。[有作用的材质、颜色与光源]。
[仅在需要时：画内逐字文案、位置、层级]。[整体构图关系]。
```

现行本地路线可按档案用中文；选择官方 T2I PE 时，再编译为其英文观察式正文。
短例（中文本地写法）：

```text
一张陶壶的编辑摄影。乳白陶壶位于深木桌面的右下方，左上是留白的温灰墙面。
右侧窗光照亮细密釉面，桌上保留宽而柔和的投影，构图安静而疏朗。
```

已有精确 brief 先轻修；不为凑长度擅加物件、文案、人物或未获委托的主题。

## 4. HEX 整理：编辑与参考

```text
[编辑动作]输入图中[目标属性/区域]为[明确可见的新状态]。
[画布图]负责构图和未修改内容；[参考图]只提供[已确认职责]。
保持[关键不变量]。[只补必要的融合、边缘和接触关系]。
```

单父图短例：

```text
将图中车辆的车漆改成暖玫瑰粉高亮漆，使漆面形成连续整洁的宽幅高光。
保持车辆身份、拍摄角度、轮毂、灯组与场景构图不变，门缝和车身轮廓清晰。
```

如果另有漆面参考，只指明取其漆色/质感，不把参考车的比例与零件带入。
只有真实入口支持多图且采用官方 PE 时，才按输入顺序用 `<image1>` 等标签；现有单父图连接器不因此获得多图能力。
借主体另创场景需要设计新构图；修改当前画布则保护未指定改动，不能用“优化”概括全图重绘。

## 5. 正文、PE 输出与工具参数分开

- 官方 T2I PE 输出 `rewritten_prompt` 与 `wh_ratio`；Edit 另有 `ratio_follow`。[Q2][Q3]
- Edit 的 `wh_ratio` 和 `ratio_follow` 互斥；图像正文取 `rewritten_prompt`，适配器负责映射比例。
- 此 JSON 不等于所有 Qwen API 的请求体，也不是交给用户填写的技术问卷。
- 原尺寸、透明通道、蒙版、多参考及采样参数由实际接口决定；提示词不能保证像素无损。
- 本地 CFG=1 等设置仍服从已绑定路线；不能把基础版设置套给 Turbo，或凭名称启用未接入能力。
