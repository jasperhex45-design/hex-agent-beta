# Seedream：图像生成与编辑写法

checked: 2026-10-12；状态：官方资料已核对，HEX 对应路线仍为 experimental。
本卡是知识缓存；不表示独立官方 API、新版本或图层功能已接入。

## 1. 型号与入口先明确

- Seedream 是图像系列；Seedance 是视频系列，不能混用镜头时间线、音频引用和视频参数。
- 已核实 Seedream 5.0 Pro；当前官方 API/教程另列 Flash、Lite 及 4.5、4.0。[S1][S3][S4]
- 用户只说“5.0”时，按当前上下文确认 Pro/Flash/Lite 与实际平台；涉及版本差异不能擅自补完。
- 本工程已有小云雀 CLI 路线，具体历史实参范围见 `knowledge/models/seedream.json`。
- CLI 服务名、网页产品名与官方 API model ID 分开记录；本卡不证明它们一一对应。
- 用户未明确目标模型且当前任务没有已确认选择时先问；用途、主体含义或修改范围模糊也先问。

## 2. 官方提示组织要点

- BytePlus 官方综合指南提倡连贯自然语言，围绕用途、主体动作、环境、风格、颜色、光照与构图组织。[S2]
- 只写适用于当前任务的部分；清晰表达比堆叠质量词重要。[S2]
- 修改内容与保留内容分别说清，参考图逐一说明取主体、材质、布局还是风格。[S2]
- 需要渲染的文字放在双引号中，保留用户给出的准确字符与顺序。[S2]
- Pro 官方说明支持结合点、框、涂画和箭头指向局部，再用自然语言说明变化。[S1]
- 老通用指南在不同语言页的覆盖范围不一；URL 写“4.0–5.0”不证明其全功能适用于 Pro/Flash。[S5]

## 3. HEX 整理：新建图像

以下骨架是 HEX 根据官方资料整理，可按任务省略无关部分：

```text
为[用途]生成[图像类型]。画面呈现[主体与动作]，位于[环境]。
采用[媒介/风格]，用[构图、颜色与光线]组织画面。
[如有准确文案：在指定位置写“逐字文字”，说明字号层级与排列关系]。
```

短例：

```text
为陶瓷展生成一张竖版海报。乳白陶壶位于画面右下，背景为温灰纸面，左上留出标题区域。
柔和侧光显出细密釉面和沉静投影。左上写“器物之间”，标题下方写“当代陶瓷展”。
```

这段具体视觉选择仅是示例，不作为所有海报的默认模板。
用户已有清楚的媒介或色彩意图时沿用，不自动把插画、厚涂或平面任务改成写实摄影。

## 4. HEX 整理：参考创作与原图编辑

```text
在图1中将[目标元素/属性]改为[可观察的结果]。
图2只提供[指定参考职责]。保持[原构图、身份及未修改内容]。
让修改处的[光照、材质、边缘或接触关系]与原场景一致。
```

短例：

```text
将图1汽车的橙色车漆改为图2的珠光绿色，图2只提供漆色和漆面质感。
保持图1的车身结构、镜头角度、轮毂、灯组及环境不变。
车漆颜色均匀，形成连续柔和的宽幅高光，车门边缘和腰线清晰。
```

参考职责必须与实际提交顺序一致；没有传图时不能写成模型已经获得参考。
借参考重新设计场景时写清新的场景与构图；局部编辑不顺手重排场景或修理未被要求的细节。

## 5. 定位、画幅与参数

- 实际入口支持 Pro/Flash 交互编辑时，可用真实标注辅助定位；不虚构点、框或蒙版。
- 官方坐标示例采用 `<point>` / `<bbox>` 和 0–999 归一化坐标，不是原图像素坐标。[S6]
- 坐标从真实选区计算；未拿到定位信息时先按可见目标描述，关键范围不清就问。
- 当前 API 对 Pro/Flash 图片生成允许选分辨率档位，再用自然语言描述比例、形状或用途；实际映射服从所选入口。[S3]
- CLI 的 ratio/resolution 与 API 字段不可互换；尺寸、数量、输出格式等由工具设置承担。
- 图层拆分需真实支持的 API 与返回图层处理，不是正文写“分层”就等于 PSD。
- 模型参考与局部定位提高控制，但不能只凭提示词承诺车辆结构或非目标像素完全不变。
