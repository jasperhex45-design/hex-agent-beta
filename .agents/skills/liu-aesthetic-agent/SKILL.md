# HEX 通用视觉方法

本 Skill 只补当前任务的设计方法。旧名直接触发时，先按 [统一入口](../../../CODEX_START.md) 完成需求判断并准备/恢复任务；已经进入 HEX 时沿当前 `host_context` 继续，不另建合同或重复加载启动说明。

## 素材与可迁移关系

`open_creation` 可只有文字；`reference_transfer` 必须亲见相关参考；`local_edit` 必须有真实父图。缺必要身份或编辑素材不改称开放创作。身份图只决定身份，风格图用于绘制/摄影方法；只借画风时，不顺带复制原角色、服装、道具和标志性布局。未知焦距、灯具或制作工序保持推断。

开放研究按 [设计研究](references/design-study.md) 观察并取舍，已有指定方向或局部修改沿统一入口的对应路线。用真实 findings 与 `choices.reference_uses` 说明采用的方法怎样改变本题决定；不以链接、形容词或文本命中冒充看过作品。

## 形成有效画面

沿当前 Need / Plan / choices 设计，静态图保持 `narrative=null`。从主体关系、空间尺度、动作、视觉重心、光影、色彩和媒介中选真正影响本题的手段。写具体可见关系、配合作用、代价与失败条件；不要求填齐全部维度，也不用“高级”“电影感”代替设计。

分清用户锁定、画面成立所必需、允许变化与可以省略的内容。`spec.locked_facts` 保留 `need.must_keep`，operations 不越界，`evidence_targets` 对应 checks。允许变化保持弹性，不在编译时变成硬限制。提案需要比较时使用现有 `creative_directions`，不固定数量或为每案生图。

允许戏剧性、强色、颗粒、模糊、高密度或克制表达，以是否服务本题为准；不把低饱和、纪实、无瑕或平均照亮当通用美感。保留用户已认可的关系与风格强度，有界修改不重开范围外创意。整体表达未成立先回到设计；局部纹理与提亮不能代替整体。

## 方法依据与回到执行

只采用当前阶段提供的适用知识候选，核对领域、版本、状态与范围，允许零采用。自主假设如实用 `basis=agent_hypothesis` 与空机制引用，不伪造卡片；私人经验和反馈只按当前真实策略使用。

方案确定后回到统一入口的目标模型编译、执行与交付，避免在此复制另一套流程。每个目标保留同一必要关系与自由度；以当前编译上下文确认模型写法。真实图片中的整体效果由实际观察及用户反馈判断，方法存在或结构检查通过不证明审美提升。
